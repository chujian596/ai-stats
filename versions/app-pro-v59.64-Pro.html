使用说明


      
一、录入订单（基础操作）

      

        1. 顶部先选客户："客户:散客" 下拉切换，选谁就记到谁名下

        2. 在输入框写订单，点 保存 入账（回车=换行，不是保存）

        2.1 设置 → 录入 → 保存前预览 可开关；默认开，关掉后保存直接入账

        3. 一笔一行，可多行一次保存

        4. 保存后每行显示识别结果（特号/平特/连肖…），核对无误再下一笔

        4.1 保存后不再自动跳到「订单记录」；需要核对时点「查看本次订单」按钮，页面会定位并高亮本次订单

        4.2 订单页可搜客户/号码/金额，并按「全部日期 / 今天 / 只看香港」筛选

        4.3 「今日对账」把返水、飞后净、含返水到手、上家结算分开列；返水默认不计，需在飞单卡片勾选并设比例

        5. 输入框右上角实时显示本周累计（特号数 / 平·连 / 二·三）
      


      
二、支持的订单格式（全部）

      

        ① 特号（买号码）

          03 10 05　03-10-05　03,10,05　03、10、05　都能认

          例：03 10 05 100 = 三个号共100（按100算总额）

          例：03 10 05 各100 = 每个号100



        ② 特肖（买生肖全部号码）

          虎500　特虎500　特肖虎500　马龙兔各50　特肖龙虎兔100



        ③ 平特（平特肖）

          平虎500　平肖虎500　虎平500　平特马500　平特马龙兔各50　马龙兔平特肖100



        ④ 连肖（二/三/四连）

          连肖龙虎兔100　龙虎兔三连肖100　平连龙虎100　三四连肖虎马龙兔100



        ⑤ 组合玩法

          二中二 03,10 100　二中二:03,10 100　03,10二中二100

          三中二 03,10,22 100　三中三 07,24,32 100　07,24,32三中三100

          三中三:07,24,32 100　（用横杠写的 07-24-32 也会自动识别）

          港澳可同单录：单独一行「香港：」后续整段进香港，「澳门：」切回澳门；单行写「香港牛50」也会把后面未标注行带入香港段。



        ⑥ 快捷批量写法

          头数：0头200（=01~09全买）1头100（=10~19）

          尾数：尾5 100（=05/15/25/35/45）尾0 100（=10/20/30/40）

          生肖全包：虎数100（=虎的全部号码）

          号码各金额：09 19 29 39 49 各40（每个号40）

          号码+金额成对：03 10 05 20（=03号10元 + 05号20元）

          多笔一行：虎500羊400（自动拆成两笔）

          中文金额：虎两百　龙一百　马三百

          单位后缀：元/块/米/块钱 都忽略，如 虎500元

          金额怎么算：见下面第三节「金额歧义规则」

前缀："新澳"、"澳" 自动去掉；"特码:"、"特:" 只是标记不参与计算
      


      
三、金额歧义规则（什么时候弹窗）

      

        原则：一笔钱要分给 2 个以上对象、又没写明单位（各号/各数/各肖），就弹窗让你选；只有一个对象，或写清了单位，直接算。



        会弹窗（多选题）

        1. 特肖（按号码算，一个肖也弹）

          特马5 → 平分5（5号共5）／每号各5（25）

        2. 平特多肖（按肖算，多肖要问）

          平特马龙50 → 共50（每肖25）／每肖50（共100）

        3. 红波/蓝波/绿波

          红波10 → 总额10（摊17号）／各号10（170）

        4. 单数/双数、大/小

        5. 波色+单双、波色+大小（红波单10、绿波大5）

        6. 合数单/合数双

        7. 裸号码 2 个以上（05 17 29 10 → 各号10／共10）

        8. 头数、尾数（3头10、尾3 10）

        9. 4 个数字（两笔／各X／共X／重新编辑）

        10. "每一个"的写法都认

          各5 / 各号5 / 各数5 / 每个5 / 个5 都一样：每个号码各5

          每号5 / 每注5 / 每码5 / 每肖5 / 每只5 也认，都等于「各5」，不弹窗

          金额是三位数（100 / 120 / 500）一律当金额，不会被拆成号码

          共5 / 总共5 / 合5 都一样：总数5，摊到各号


        11. 一行多项只弹一次

          整批里只有"没写单位的"才进多选题：平龙马250（多肖）、红波10（17号）

          弹窗一次列全部，每项点一下选"共X／每肖X"，选中变浅灰底黑框带 ✓，

          全部选完"确定"才可点，只弹这一次


        12. 想用旧版本

          地址后面加 ?ver=v58.63 就直接打开那一版（v58.45~v58.65 都有存档）

          不加就永远是最新版；AI 识别已撤销，现在只走本地解析



        不弹窗（单选题）

        1. 平特单肖：平特马80 = 80

        2. 单个号码：05 10 = 10

        3. 三中三/二中二/三中二：一组一个价，三中三:19,16,35 8 = 8元

        4. 连肖：不管几个肖都是一注，连马龙兔各10 = 10元（不按复式展开）



        识别顺序：①末尾取金额 → ②剩余按空格拆段 → ③每段依次匹配 组合格式(三中三:xx,yy) → 连肖 → 产品长名 → 单个号码
      


      
四、开奖与自动结算

      

        1. 点 自动获取开奖 → 拉最新号码并结算

        2. 每天 21:33-21:35 自动获取：号码逐个跳出，稳定后自动结算

        3. 顶部时钟在开奖时段变红闪烁 = 正在刷新中

        4. 彩球显示开奖号码（红/蓝/绿波），特号带金边

        5. 备用手动：输入 开 期号 六个平号 + 特号，例 开318 10.36.02.09.26.37 + 38

        6. 结算错了 → 设置 → 撤销开奖记录 重来
      


      
五、客户 / 订单 / 账单日

      

        1. 客户统计：按客户看单量和金额

        2. 历史订单：每个客户右侧"复制 / 撤单"，点客户名展开明细

          · 撤单 = 删除该客户当期全部订单（会二次确认）

        3. 订单对账：一键"复制汇总"发给客户核对

        4. 今日归档：把当前账本封存、开新的一天；历史账本可切换查看

        5. 清除订单：清空当期订单（不可恢复，谨慎）
      


      
六、飞单统计（分批飞单）

      

        1. 阈值 = 每个号码最多自留多少，超出的才飞

        2. 阈值填 0 = 不削（全部自留，一个都不飞）；填得越小留得越少、飞得越多

        3. 不确定填多少：勾 自动稳健，系统按当天盘面自动挑一个亏得最少的档填进去

        4. 分批飞单流程：

          - 快截止时：复制本轮飞单 → 发给上家 → 点 确认本轮飞单

          - 之后又进新单：再打开飞单统计，只算新增部分，重复上面动作

          - 新一期开始：点 重置已飞 清零

        4. 页面显示：应飞总额 / 已飞累计 / 本轮应飞

        5. 配套查看：持仓分析（飞单后）、特号持仓、飞单明细
      


      
七、统计与风控

      

        1. 排行榜：特号累计，左右两栏对照

        2. AI统计：风险/集中度分析（开奖前预测）

        3. 盈利统计：本期盈亏明细，可"复制盈亏明细"

        4. 平特肖：平特单品累计

        5. 产品累计：按产品看总量
      


      
八、赔付与对账

      

        1. 赔付页显示：销售总额 / 总赔付 / 净收入

        2. 倍数（默认47，按你的玩法改）→ 选特号 → 按倍数记赔付

        3. 赔付记录列表可逐条删除，"清空赔付记录"一次清完

        4. 设置里 生成对账单 一键出账

        5. 功能设置里 导出统计CSV 可用表格打开
      


      
九、数据备份（重要）

      

        1. 数据存本机，并自动双备份（localStorage + IndexedDB），清缓存不容易丢

        2. 备份JSON：把全部数据导出成文件，建议每天存一份

        3. 导入备份：换手机/重装后选JSON文件恢复；手机选不了文件就用旁边的粘贴导入，把备份内容直接粘进窗口

        4. 一键恢复上次备份：误操作后快速回滚

        5. 清空全部数据：全部清零且不可恢复，非必要别点
      


      
十、界面与产品设置

      

        1. 外观：黑 / 白 / 灰 三套背景，随系统日夜模式自动切换（装App时）

        2. 产品设置三块：

          ① 子产品 01-49：改颜色、备注名（默认1-49，可加编号）

          ② 主产品/套餐：12个空位，点名字改成你的产品名，勾选包含哪些子产品

          ③ 单品：12个空位，点名字改成商品名

        3. 恢复默认：外观和产品设置还原
      


            
十一、香港单与飞单（港澳分开算）

      

        1. 怎么录

          顶部切到「香港」可以录；在澳门店也能直接录香港单

          单独一行「香港：」→ 后面整段进香港；「澳门：」→ 后面整段切回澳门

          单行写「香港牛50」也会把后续未标注行带入香港段；行尾写「…澳门」只把该行算澳门

          同一客户的澳门单和香港单在同一张客户卡合并算下注/中奖，明细仍分「澳门单目录 / 香港单目录」，每笔前面还有「澳门」或「香港」小标



        2. 独立一池

          香港单进全局香港池，澳门店和香港店都能看到；订单、开奖、赔付、飞单、结算仍按港澳分开存，互不串号

          澳门削峰和澳门上家飞单不把香港单算进去；香港单也不套用澳门开奖



        3. 香港工作台

          有香港单才出现，默认收起；标题显示香港单数、已飞/待飞/记录金额和凑整档

          展开后按「待飞目录 / 部分已飞 / 已飞目录 / 只记录」四段分开，每段带项数和合计

          已飞明细可上下滑动；「复制香港单」只复制本批要飞的内容



        4. 飞单默认总开关

          顶部「香港飞单默认（所有客户）」一个开关管所有客户：

          全飞 = 所有香港单都飞给上家

          只飞组合 = 只飞连肖/二中二/三中二/三中三，单号和平特只记录

          只记录 = 全部不飞，只记客户账

          改档后本批自动回到待确认，不会沿用旧档位；不再需要逐客设置



        5. 连/二/三自动飞

          勾选「（连/二/三）自动飞」后，连肖/二中二/三中二/三中三直接算已飞，不再进待飞

          单号、平特仍按手动确认；新增香港单只把新增部分回待确认，已经飞过的金额保留，不会清零

          自动飞项会计入「已飞」，复制香港单时不再重复复制这些组合项



        6. 凑整与香港实际

          点标题里的「凑整关 / 凑整5 / 凑整10」循环切换；订单行显示凑整后的飞额，「收」仍按客户原单额

          「应飞」显示原额和凑整后目标（如 507 → 515）；「已飞」按凑整后实付记账

          香港实际 = 收 − 赔 − 已飞 + 上家赔回；凑整差单独标出，正数表示多飞自己多付，负数表示少飞自己留



        7. 确认与结算

          工作台右上角「确认」或底部「确认已飞」只记香港飞单账，不写澳门上家；澳门的「确认本轮飞单」是另一本账，两个入口分开

          「结算香港本批」独立写香港赔付，不写澳门结算；「港澳合计」只做只读核对



        8. 香港开奖/赔付

          有香港单才出现香港开奖条；澳门店里的香港单也按香港开奖算，不再显示“香港开奖未录入”

          香港不是每天开，期号比澳门旧是正常的；没拉到香港开奖时显示待开奖，拉到后自动算收/赔/净

          赔率和澳门同一套（特码 47 倍、平特 1 赔 2），不用另设



        9. 删香港单

          每笔旁边有删除；客户撤单会连香港单一起删，并提示删了几笔
      



十二、分店切换（右上角）

      

        1. 点右上角「澳门🇲🇴▾」→ 选「香港🇭🇰」，页面自动重载

        2. A 店＝澳门：默认收澳门单，带「香港」标注的行自动进香港账

        3. B 店＝香港：默认收香港单，带「澳门」标注的行自动进澳门账

        4. 两本账分开存，但同一客户的港单和澳单会在客户卡片里合并显示

        5. 分店就是这个切换，不用另外的网址
      


      
十三、常见问题

      

        1. 一笔认不出来 → 整笔报错，不会只存一半，改好再存

        2. 按回车没保存？回车是换行，要点"保存"按钮

        3. 开奖后忘记归档 → 先结算，再点"今日归档"

        4. 换了手机 → 旧机"备份JSON"，新机"导入备份"

        5. 页面没更新 → 系统会自动比对云端版本并强制刷新，等几秒即可
