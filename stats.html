四个入口

本期数据只回答一件事：这一期各站公开资料汇总后，九肖、杀三肖、平特、波色、尾数、头数、大小、单双分别是什么结构。
逐站明细把每一站的原始栏目和推荐列出来，可按站名或固定 ID 搜。
历期复盘看某一维度最近几期的覆盖、命中、错误和命中率。
开奖记录看最近开奖号码与特码。

票数口径

1 个站、1 个栏目算 1 票（站次）。九肖每站给 9 个肖，所以九肖总票数会明显大于站点数；杀三肖每站 3 个肖，同理。页面上写“票”，实际是站次，不是金额，也不是下注量。

命中规则

九肖：开奖特肖在站方给的 9 肖内，记“中”；杀三肖：开奖特肖不在站方杀的 3 肖内，记“杀中”；平特/波色/尾/头/大小/单双：按对应栏目是否覆盖开奖值记中错。大小、单双只取纯“大小中特”“单双中特”，不混“2期大小”“合数单双”“大小肖”等复合栏。

站名与固定 ID

每个站都有固定 siteId 和站名，台账按站名 + ID 回溯，避免只留匿名票数。当前 77 站全部有名字；4 个 bdmijg 聚合站公开页没有中文品牌名，使用稳定的“聚合站143/182/51/64”代号，并标明是派生名，不冒充品牌。

更新时间

每天四个节点：09:30、15:30、20:00、22:30。20:00 封存当期资料；同一期多份快照按站点并集、栏目并集累计，晚班漏抓不会把下午的票数打回去。开奖后 22:30 入账并切到下一期。

数据存在哪里

页面本身不存数据，只读同站点的 JSON。本期汇总在 data/current-recommend.json，站点目录在 data/site-directory.json，八本逐站台账在 data/ 下的 max-zodiac / kill3 / pingte / wave / tail / head / size / parity 八个 ledger.json；原始抓取快照在仓库 snapshots/，按“期号+时间”命名。页面和这些文件一起放在 chujian596/ai-stats 仓库，GitHub Pages 直接读取同目录的 data/。

数据来源

本期汇总读取 current-recommend.json；逐站来自同一份快照合并结果；历期来自九肖/杀三肖/六维逐站台账；开奖来自开奖镜像。所有数据文件都在站点根目录的 data/ 下，可直接复查。
