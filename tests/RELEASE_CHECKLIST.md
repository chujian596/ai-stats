# 发版质检清单（每版必做）

任何改动（解析规则、弹窗、样式、版本机制）在推送前必须全过，未过不许 push。

## 一、自动项（一条命令）

```bash
bash tests/release_check.sh
```

包含：
1. 语法门禁：抽出所有 `<script>` 交给 `node --check`
2. 回归：`tests/coverage_check.py` → 107 项（专业版 + 客户版各跑一遍），要求 **失败 0**；含 `每数各/每号各`、多尾 `尾1.2...9`、多头 `头1.2.3.4`、尾数/头数各号、头数 0/4 的金额断言
3. 线上版本核对（可选，推送后）：`APP_VER` 与 `version.txt` 一致
4. 真实单截图回归：`01.13.49.21.33.45.02.38.每数各100。` + `06.18.30.22.34.46.每数各40。` 必须一次保存 14 号、合计 1040 元
5. 混搭命中/赔付回归：浏览器执行 `tests/settle_mixed.js`，要求 4/4 PASS、failures 0：
   - 特号+二中二+三中三：单 480，赔付 25700（二中二两个号都在 6 平号内）
   - 特号+二中二+三中三+平特+连肖：单 880，赔付 27280（平特含特号生肖，组合不含特号）
   - 同号重复 100+50：合并 150，命中赔 7050
   - 特号不算组合：二中二03,10 里 03 是特号，不判中；单 480，赔付 22700

## 二、人工项（浏览器实测，必须逐条看结果）

启动：`cd ai-stats && (nohup python3 -m http.server 8099 >/tmp/http9.log 2>&1 &)`
页面：`http://127.0.0.1:8099/app-pro.html?nock=1&t=<随机>`
先清 `localStorage.removeItem('aiProPinVer')`

### A. 该弹窗（15 条）
特马5、平特马龙50、红波10、蓝波5、单20、双15、大15、小10、
红波单10、绿波大5、合数单10、05 17 29 10、3头10、尾3 10、16 28 49 05

判定：都弹，弹窗文案正确。

### B. 不该弹（12 条）
平特马80=80、05 10=10、连马龙兔10=10、02 15二中二10=10、
19 16 35三中三8=8、特马各5=25、特马各数5=25、特马各号5=25、
特马每个5=25、红波各5=85、红波各号5=85、狗各数5=20

判定：直接落账，金额一致。

> 注：`红波各5=85`、`红波各号5=85` 这两条 **node 测试环境算不对**（无 DOM 时波色展开路径不同），必须以浏览器实测为准，不能只看脚本结果。

### C. 多选合并
- `红波10 单20 大15` → 一个框 3 项，全选"共" = 45 元
- 整批 15 行（狗各数100 … 红波10）→ 一个框 **2 项**（平龙马、红波），选共250/共10 = **2325 元、68 项**

### D. 明细与样式
- 波色"每号X"在明细里合并成一行 `N个号 每号X = 总额`
- 选中项：浅灰底 + 黑边 + ✓；未选：白底灰字
- 确定按钮：未选完白底灰字灰边（`确定（还差N项）`），选完白底黑边黑字

### E. 其他功能
- 开奖录入、订单记录、排行榜、飞单统计、对账单、撤销开奖、功能设置弹窗能打开
- 手动录入（12 种类型）能存
- 版本入口：`?ver=v58.63` 能跳到旧版；当前版号不跳；不存在版本不跳

### G. 浏览器端到端门禁（自动）
`bash tests/release_check.sh` 第 5 步会跑 `tests/browser_gate.py`，必须看到：
`QA 116/116、词库 154/154、混搭 4/4、选择对账 55/55、录入金额 38/34、归档/日志 36/36、开奖按钮 2/2，共 405/405`，失败禁止发版。

### H. 历史归档自检（真机）
打开「历史账单」，顶部应显示「历史归档自检通过」或差异明细。
造一条差额/重复，确认能标出；点「写入错误日志」后，设置→错误日志能看到 `archive_audit` 和账本日。
点「查看明细」进入疑似重复的日期，确认重复行有「作废这一笔」；作废后当天单数/收/赔/净应重算，错误日志出现 `bill_void`。
自检口径：只有“同一天 + 同客户 + 同原文 + 同金额 + 3 分钟内”才进黄色“建议核对”；同天隔久、跨天同内容不应报。
一次粘贴 2 行以上无法识别的内容，应直接弹出「有 N 行没识别」，点「复制失败清单」应能复制；设置→错误日志顶部也应显示“无法识别 N 次 / M 种”。
设置页点「复制诊断」，应能复制版本、订单量、存储、错误数和失败原文，不需要去文件管理找 JSON。
录入 `平龙10三中三11.22.33组5`，预览应为两笔：平特龙 10 元、三中三 5 元，合计 15 元；明细里不能出现号码 10。
本期已经结算过再点「自动获取开奖」，按钮必须恢复可点，不能停在“获取中...”或文字正常但点不动。
服务器只返回上一期时，应提示旧数据；提示关掉后按钮同样要恢复可点。
点「清除订单」后，订单记录必须立即变空；切到另一店铺再回来也不能复活旧单。
没有开奖记录时，订单中奖必须是 0；撤销开奖后再点客户「复制」，也不能带出旧号码的命中。

录入一行无法识别的内容，确认错误日志能看到账本日 + 原文。
