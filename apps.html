常见问题

为什么会员管理新版要卸载

原因
v1.0 是第三方工具打的包，签名 99d155…，私钥不在本机，签不出能盖它的包
解决
卸载 → 装 v1.1；以后同签名直接覆盖

APK 为什么不怕断网

原理
打包时把整页塞进 assets/shell.html，启动用 loadDataWithBaseURL 直接渲染，不走网络
老版本
v1.0 会员管理没有 assets 目录，只加载线上地址，没网就白屏——这就是「离线」的真相

页面改了但手机上还是旧的

网页端
GitHub Pages 有 CDN 缓存，改完要等几分钟；Cloudflare 域名 aistats-9uo.pages.dev 即时生效
APK
用内置页面，不受缓存影响；但要看到新页面必须重打 APK

版本号卡住不动

症状
页面显示版本比 version.txt 旧，改了几轮都没变
原因
之前用「带旧值的字符串替换」改版本号，前提不成立会静默失效
规矩
一律用 re.sub(r"APP_VER\s*=\s*'v58\.\d+[^']*'", ...)，别写死旧值
维护方式：新增应用或改版本，同步更新本页 + 版本说明.md。
本页随仓库部署，手机可直接打开。
